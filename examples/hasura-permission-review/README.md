# hasura-permission-review example

Hasura v2 metadata for two tables and a `user` role. The JWT claims
(`https://hasura.io/jwt/claims`) provide `X-Hasura-User-Id` and `X-Hasura-Org-Id`.

Run from the repo root: `/hasura-permission-review`

What's planted is listed in
[docs/hasura-permission-review.md](../../docs/hasura-permission-review.md) — kept out of
this folder so the skill can't read the answer key.
